# MCP Servers

[Parent: General](README.md)

**Always check and use MCP servers available.**

- At task start, discover the available servers and relevant tools/resources. Do not assume integrations from another project are present here.
- Use the relevant available MCP integration for the task rather than bypassing it with an equivalent manual workaround.
- Confirm that a project-bound server, especially Unity Editor tooling, targets the intended project before relying on its data or changing anything.
- Read the tool's advertised schema and instructions; do not guess names, parameters, capabilities, or connection status.
- Use only relevant tools. Availability is not a reason to call every server or repeat discovery unnecessarily.
- MCP access does not authorize scene changes, Play Mode, tests, builds, exports, or destructive operations.
- If the relevant server is unavailable or fails, report the limitation and use a suitable authorized fallback. Never claim MCP verification that did not occur.
- For the phase-based workflow routing across MCP servers (`agentmemory`, `sequential-thinking`, `context7`, `serena`, `roslyn-mcp`, `ai-game-developer`) and adversarial verification skills, see [Agent Workflow Tree](../../Agent_Workflow_Tree/README.md).
